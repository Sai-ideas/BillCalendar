# BillCalendar 產品需求規格（V0.3）

## 目的與原則
開發 Jorte 式高密度月曆結合 ienon 式家庭協作的示範應用。**獨立儲存模組，藉日期摘要與資料關聯整合**。預設私人；家庭共享是明確的資料歸屬選擇，不會使私人日記公開。

## 使用者與空間
- 使用者有穩定內部 user_id，Email 在測試環境作唯一選擇鍵（標準化及唯一約束），不作外鍵主鍵。
- 一個使用者可加入多個家庭；每家庭包含成員與角色、行事曆、共享待辦、帳本及**一個**聊天室。
- 個人心情為個人 Chat Room，不建獨立 mood entries 資料表。
- MVP 使用虛構 Email 身份選擇而非 Google OAuth；不得用於真實個資、財務或隱私內容。

## 功能需求
### 月曆與事件
- 月曆為主要入口，西曆與農曆並列，顯示日期及節慶（資料來源與正確性待驗證）。
- 日期格可顯示事件條、待辦及「有聊天／有記帳／有私人日記」標記；標記僅呈現是否存在，不洩漏資料內容。
- 選擇日期更新右側詳情；點圖示直接切換對應分頁及定位日期。
- 支援個人／家庭 Event CRUD；Event 描述有時間安排，與 Task 分離。
- 農曆每年重複排程（包含閏月）暫非 MVP；不要將簡單農曆顯示誤作已支援農曆重複事件。

### 待辦
- 個人及家庭待辦；可無日期、可有截止日期；含完成狀態。
- 與 Event 不同資料表及生命週期；訊息可建立 Task。
- 家庭待辦的指派、通知與循環規則為後續擴充。

### 心情／聊天
- 「心情」只是個人聊天室的 UI 名稱，支援文字、emoji、快速筆記、外部圖片網址。
- 每個家庭恰好一個聊天室，家庭成員共同參與。
- 按時間保存訊息，日期可定位到當天消息；不要強制只顯示那天，以免失去上下文。
- 訊息可建立事件／待辦，保存關聯，從新紀錄回看原聊天；原文保持不變。
- 訊息可複製到日記**編輯草稿**，須使用者確認儲存，日記永遠私人。
- MVP 可輪詢，不承諾即時 WebSocket／已讀等進階聊天功能。

### 私人日記
- 僅 user_id 擁有者可讀寫，允許一天多篇，文字與外部圖片 URL；禁止公開或家庭共享日記。
- 可從個人或家庭聊天複製訊息成草稿，原文及其權限不變。

### 記帳
- 個人帳本及家庭帳本；收入／支出、分類、記錄日期及月度統計。
- 金額儲存為整數最小幣值單位並記錄幣別；個人與家庭收支統計不重複計算。
- 分攤、代墊結算、CSV 與定期記帳可後續實作。

### 外部圖片
- 不提供上傳、不儲存圖片位元資料；D1 只存 HTTPS URL 和必要元資料。
- 僅以安全的圖片渲染／允許的嵌入方案呈現，無法載入時保留連結；不能假設 Imgur 分享頁就是直連圖片。
- 圖床限制、失效、追蹤與隱私風險須於 UI 提示；避免未受信任 HTML、javascript: URL、SSR F。
  
## 非功能與限制
- 部署 Cloudflare Workers + D1，不依賴信用卡綁定的 R2。
- 服務端每次檢查空間權限，不能依賴前端隱藏按鈕。
- 一次回傳月曆摘要，按需載入單日資料／聊天室分頁；避免全月訊息全文下載。
- 日期以明確時區（預設 Asia/Taipei）計算；時間戳以 UTC 儲存，全天日期獨立處理。
- 測試身份選擇沒有真實身份驗證，環境須限權及使用合成資料。

## 初版可驗收使用情境
1. A/B 以虛構 Email 選擇不同身份；A 的私人心情／日記不能經正常操作被 B 看見。
2. A 建立家庭並邀請 B；兩者可看家庭事件、帳本和同一聊天室。
3. B 在家庭聊天室留言，A 從該訊息建立一筆家庭事件；事件頁能返回該訊息。
4. A 從聊天建立私人待辦及日記草稿；B 不可見該私人紀錄。
5. 日期格有聊天、帳本、日記時顯示相對應圖示，點擊定位正確的日期及功能。
6. 選擇過去日期時，聊天捲至該天訊息且可繼續查看上下文。
7. 貼圖片 URL 可顯示或保留失效連結；系統不接受圖片檔案上傳。

# UI 與互動規則（V0.3）

## 參考
Jorte：月份格子顯示多行行程、彩色事件條、農曆與小圖示。
ienon：分頁切換聊天室／記帳／心情／日記。這是**設計參考，不直接複製素材**。

## Desktop 結構
- 頂端：空間切換（個人或家庭）、月份導覽、帳號。
- 左 60–65%：月曆；每格有陽曆、農曆、事件／待辦條、活動標記。
- 右 35–40%：功能分頁：**摘要、心情、聊天、記帳、待辦、日記**。
- 手機版：優先月曆，右面板改分頁／底部 sheet 或獨立畫面，維持日期選擇。

## 導覽與日期
- 全域 `selectedDate` 與 `selectedSpace`，不等同 today；切月時應合理保留／更新選取日。
- 點日期空白處：選擇日期並開摘要。
- 點日期格事件：開該事件詳情。
- 點聊天 icon：定位選取日期相關聊天；個人與家庭同日有訊息時，使用明確選擇規則（尚待定），不可意外洩漏私人內容。
- 點帳本 icon：開該日收支；點日記 icon：開私人日記。
- 若同日無紀錄，不顯示相應標記。每種 icon 代表**存在**，非公開內容預覽。
- 摘要顯示當日行程／待辦／收支及其他紀錄，並提供進入各模組的入口。

## 心情與聊天
- 「心情」是個人聊天室標籤；聊天是目前家庭的唯一聊天室。
- 各自使用同一個 ChatPanel 元件，允許 emoji／快速文字筆記／外部圖片連結。
- 點選過去日期後定位對應日期分隔線附近，但仍可前後捲動，不硬過濾成當日訊息。
- 訊息的操作選單：建立事件、建立待辦、複製為私人日記草稿。
- 轉事件／待辦開啟表單，預填訊息文字，日期及時間由使用者確認；儲存後訊息旁可看到關聯紀錄。
- 事件／待辦詳情有「查看來源聊天」；跳轉時選聊天室、捲至訊息、高亮；如無權限則顯示不可存取，不顯示原文。
- 日記草稿由原始訊息複製內容及可用的圖片 URL，儲存後不修改原訊息，只有本人可以讀取。

## 圖片 URL
- 只接受外部 HTTPS URL，不上傳二進位檔。
- 直接圖片 URL 可預覽；非直連的分享網址只在支援且符合圖床條款時使用嵌入，其他保留普通連結。
- 載入錯誤時顯示備援連結；不保證外部圖床持續有效。

## 待確認 UI 細節
- 同日個人／家庭聊天共用 icon 的點擊優先順序。
- 不同家庭在月曆的聚合或分層顯示。
- 月曆格過多事件時的收合規則。
- 手機頁面採底部導覽或抽屜切換。

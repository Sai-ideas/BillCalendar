# UI 與互動規則（V0.3）

## 參考
Jorte：月份格子顯示多行行程、彩色事件條、農曆與小圖示。
ienon：分頁切換聊天室／記帳／心情／日記。這是**設計參考，不直接複製素材**。

## Desktop 結構
- 頂端：空間切換（個人或家庭）、月份導覽、帳號。
- 左 60–65%：月曆；每格有陽曆、農曆、事件／待辦條、活動標記。
- 右 35–40%：功能分頁：**摘要、心情、聊天、記帳、待辦、日記**。
- 手機版：優先月曆，右面板改分頁／底部 sheet 或獨立畫面，維持日期選擇。

## 導覽與日期
- 全域 `selectedDate` 與 `selectedSpace`，不等同 today；切月時應合理保留／更新選取日。
- 點日期空白處：選擇日期並開摘要。
- 點日期格事件：開該事件詳情。
- 點聊天 icon：依 `selectedSpace` 定位；個人空間顯示個人「心情」，家庭空間顯示所選家庭唯一聊天室。切換空間時更新相應存在性圖示。
- 點帳本 icon：開該日收支；點日記 icon：開私人日記。
- 若同日無紀錄，不顯示相應標記。每種 icon 代表**存在**，非公開內容預覽。
- 摘要顯示當日行程／待辦／收支及其他已授權紀錄，並提供進入各模組的入口；MVP 家庭空間不顯示私人日記圖示，私人日記只在個人空間出現。

## 心情與聊天
- 「心情」是個人聊天室標籤；聊天是目前家庭的唯一聊天室。
- 各自使用同一個 ChatPanel 元件，允許 emoji／快速文字筆記／外部圖片連結。
- 點選過去日期後定位對應日期分隔線附近，但仍可前後捲動，不硬過濾成當日訊息。
- 訊息的操作選單：建立事件、建立待辦、複製為私人日記草稿。
- 轉事件／待辦開啟表單，預填訊息文字，日期及時間由使用者確認；儲存後訊息旁**僅向有權限的使用者**顯示衍生紀錄；不得洩漏私人目標是否存在。
- 事件／待辦詳情有「查看來源聊天」；跳轉時選聊天室、捲至訊息、高亮；如無權限則顯示不可存取，不顯示原文；來源軟刪除顯示已移除，不影響獨立存在的事件／待辦。
- 日記草稿由原始訊息複製內容及可用的圖片 URL，儲存後不修改原訊息，只有本人可以讀取。

## 圖片 URL
- 只接受外部 HTTPS URL，不上傳二進位檔。
- 直接 HTTPS 圖片 URL 可用原生 img lazy loading、no-referrer 預覽；分享／相簿頁一律顯示安全外部連結，MVP 不嵌入第三方腳本、不從後端抓圖。
- 載入錯誤時顯示備援連結；不保證外部圖床持續有效。

## PR #18 決策同步
- 訊息時間軸按 `created_at`（UTC）與 ID 排序；`local_date` 是發送時聊天室本地日期，用於日期定位與圖示；`record_date` 預留補記日，不覆寫發送日。
- 站內家庭邀請以待接受清單呈現；admin/member 角色；最後一位管理員需要先交接才能退出。
- 訊息可建立多個事件／待辦，但每筆事件／待辦至多一則直接來源訊息；不顯示未授權衍生記錄的內容、數量或存在性。
- 農曆與台灣節假日顯示必須驗證資料來源、閏月與套件授權；農曆循環事件不在 MVP。
